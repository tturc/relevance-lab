# Autocomplete
Autocomplete is prefix search over a much smaller candidate set than the main index. A trie or a sorted array with binary search answers prefixes in logarithmic time, and a prefix index built from the top documents by popularity keeps the list short enough to hold in memory. The ordering question matters more than the lookup: raw token frequency surfaces junk, so candidates are usually scored by completed searches rather than typed prefixes, which means the completion log has to be joined back to what the user eventually did. Personalisation belongs last, after the spelling correction and the safety filter.
