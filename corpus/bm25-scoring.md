# BM25 scoring
BM25 is a ranking function that scores how well a document answers a query. It combines three signals. Term frequency: a document that mentions a term more often is more likely to be about it, but each extra occurrence adds less than the one before, so a page cannot win by repeating a word. Inverse document frequency: a term that appears in most documents of the collection carries almost no signal, while a rare term is highly informative. Document length: longer documents naturally contain more occurrences, so they are normalised against the average document length. The result is a single score per document that can be compared with any other, which is what makes it usable for sorting.
