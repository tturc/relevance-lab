# Spam detection
Spam in search results is an adversarial problem, and the adversarial signal is usually in the structure rather than the text. Link spam shows up as a dense cluster of pages pointing at each other. Cloaking shows up as a mismatch between what the crawler saw and what a browser sees, so detection needs a rendering fetch rather than a text fetch. Keyword stuffing is visible as an unusual term distribution for the document length. None of these signals is conclusive alone, which is why the practical approach is a score with a manual review queue behind it, not an automatic ban.
