# Crawl politeness
A crawler that ignores the cost it imposes is a denial of service attack with a friendly name. Politeness rules: read robots.txt before fetching anything, honour crawl delay, and keep concurrent connections per host low. Freshness and politeness pull against each other, and the resolution is usually a per host budget rather than a global one, so one slow site cannot hold up the queue. Identify the crawler honestly in the user agent string and publish a contact address so a site owner can complain. Log every fetch with its status code, because the politeness policy is only visible in the request log after the fact.
