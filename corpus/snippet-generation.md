# Snippet generation
A result snippet has to show why the document matched, in about two lines. The usual method: find the densest cluster of query terms in the document, cut a window around it, and highlight the terms. Cutting on sentence boundaries reads better than cutting on character count, but the window then varies in length. Highlighting must escape the source text, because a document that contains markup or a script tag will otherwise inject it into the result page. For a match with no cluster, such as a match on a term in the title, fall back to the document summary rather than showing the first two lines.
