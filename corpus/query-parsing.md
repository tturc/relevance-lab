# Query parsing
Parsing a query is deciding what the person meant, cheaply. Operators like quotes for a phrase, minus for exclusion, and site: for a host let a user express intent that ranking cannot guess. The parser should reject nothing silently: a malformed operator either falls back to plain text with a visible hint or is dropped, but it is never allowed to produce an empty result set the user cannot explain. Boolean versus ranked mode is a product decision as much as a technical one. Ranked mode answers more queries, boolean mode answers a small set of queries exactly, and shipping both means deciding which is the default.
