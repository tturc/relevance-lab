# Measuring ranking quality
A ranking change is only an improvement if a number moves. Offline evaluation uses a set of queries with human judgments about which documents are relevant and how relevant. Precision at k counts the share of the top results that are relevant. Reciprocal rank rewards putting the first relevant document high. NDCG discounts each hit by the log of its position and normalises against the ideal ordering, which makes it the metric that reflects what a user actually experiences. The weakness is pooling: judgments only cover documents someone looked at, so a new result that was never judged scores zero.
